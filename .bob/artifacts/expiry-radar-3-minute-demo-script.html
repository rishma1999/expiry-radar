🤖 PIPELINE — 5 Agents Fire  0:20 – 1:00

🎙 Say this
"Let's run the pipeline. Five independent agents, each with a specific job."

(as each agent runs, narrate it)

Agent 1: "The EOL Collector reads requirements.txt and queries the endoflife.date API — plus a hardcoded IBM and Qiskit fallback map — to find exact end-of-life dates."

Agent 2: "The Date Scanner checks every Python and Markdown file for hardcoded dates and TODO comments anchored to a code comment — false positives like author surnames are filtered out."

Agent 3: "The GitHub Issues Agent scans for every GitHub URL in the codebase, calls the GitHub REST API, and flags closed issues that still have live workaround code."

Agent 4: "The Release Notes RAG fetches the latest fifteen Qiskit releases, parses every Deprecated and Removed section, and cross-references our curated IBM and Qiskit deprecation catalog against the actual source."

Agent 5: "The Urgency Scorer merges everything and ranks by urgency score — one over days left, times severity weight, times confidence."
