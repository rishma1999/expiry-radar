# expiry-radar
IBM Bob 2.0 Hackathon - Expiry Radar

Everything in your codebase has a hidden expiration date. We find it before production does." Expiry Radar finds workarounds whose upstream fix already shipped, APIs with sunset dates, end-of-life runtimes and libraries, expiring certificates, dated TODOs, and hardcoded dates, then shows a calendar of future breakages and auto-fixes the nearest ones.
